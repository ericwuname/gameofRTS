# 06 多 AI 协作特有风险与对策

| 风险 | 症状 | 对策（机制而非自觉） |
|---|---|---|
| **80% 问题**（Sourcegraph） | AI 完成局部编辑，漏仓库级约束（3 天后别处爆炸） | 任务单强制列出受影响文件清单；Reviewer 检查调用方；禁止跨目录自由改 |
| **Swarm 冲突** | 两个 AI 改同一调用点，合并冲突 | git worktree 按窗口隔离；共享状态任务禁止并行派发 |
| **弱模型幻觉/臆造** | 编造 API、虚构数值来源 | 能力分级匹配；数值必须回指调参表；不确定即退回 |
| **验证造假（自嗨）** | "测试通过"但没跑/跑的不是同一版本 | G1-G4 证据链；证据必须带路径可复核 |
| **静默抑制** | 把报错 try-catch 吞掉/删掉警告装作无事 | 铁律 5；抑制必须显式声明条数与理由 |
| **上下文丢失** | 会话重启后失忆重复劳动或重复犯错 | handoff 协议 + 记忆日志；重复犯错入决策日志 |
| **范围蔓延** | AI 顺手多做了"明显的改进" | 只写任务单指定文件；私改设计文档 = 违规 |
| **规则文件腐烂** | 规范与实际脱节没人更新 | 决策日志强制；AGENTS.md 超 100 行强制瘦身 |
