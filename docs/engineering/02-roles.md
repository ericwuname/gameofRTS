# 02 角色与能力分级

## 角色（三角色 + 编排，跨工具同名同责）
| 角色 | 职责 | 权限边界 |
|---|---|---|
| **Orchestrator（顶层）** | 拆任务/派发/验收/改冻结清单 | 唯一可改 frozen 清单与 MEMORY.md |
| **Builder（施工）** | 按任务单实现，带 @trace 标记 | 只写任务单指定文件；禁改设计文档 |
| **Reviewer（审计）** | 源码直读验收 + 跑验证门 | 只读 + 报告；**不得自审自己写的代码** |
| **Researcher（调研/测试）** | 查资料/跑 Agnes 门/数据分析 | 不写生产代码 |

## 能力分级 × 任务匹配（POS 四级模型，弱模型只配弱任务）
| 级别 | 典型模型 | 允许的任务 |
|---|---|---|
| basic | flash/mini 类 | 文档整理、格式化、字符串表、报告汇总 |
| standard | 中档模型 | 单文件 bug 修复、按明确规格写脚本、测试补全 |
| advanced | 强模型 | 多文件系统实现、数值调参、跨模块重构 |
| reasoning | 推理模型 | 架构决策、根因分析、设计评审、难度曲线建模 |

**任务单必须标注 capability 级别**；basic/standard 模型看到超级任务必须退回而非硬做。
