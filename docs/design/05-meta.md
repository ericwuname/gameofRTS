# 05 元游戏与新手引导（缺口补全）

## 局外成长（三轨，全部不卖数值强度）
1. **指挥官图鉴**（主轨）：每局防守方指挥官随机自人格池；击败过的指挥官
   收录图鉴并解锁其"规则手记"（下次遇到同人格开局就公示其全部规则）。
   ——知识积累即成长，失败也带走情报（"没有浪费的一局"）
2. **天赋池解锁**：初始 6 个天赋可用，每完成 2 局（不论胜负）解锁 1 个新天赋
   进入随机池——扩大选择而非提升数值
3. **每日种子挑战**：当日全玩家同一张图同一指挥官，本地记录最佳成绩

## 新手引导（FTUE，三局渐进）
| 局数 | 开放系统 | 教学点 |
|---|---|---|
| 第 1 局 | 单路防线 + 单级供应链（矿→直接潮力）+ 固定"教学人格"指挥官 | 画路线、走位、擦弹 |
| 第 2 局 | +多路倒计时 + 维护费 | 取舍与收支 |
| 第 3 局起 | 全系统（精炼级链、厂型、迷雾）+ 随机指挥官 | Build 自由 |

HUD 常驻收支表（收入/维护/净流）。跳过引导的入口常开。
