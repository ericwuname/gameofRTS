# 07 数据埋点 / 商业化 / 无障碍与本地化（缺口补全）

## 埋点事件（本地 JSONL，不上传，为调参服务）
| 事件 | 字段 |
|---|---|
| run_start / run_end | seed、指挥官、局时、结果、破产归因 |
| node_capture | 节点类型、时序、舰队构成 |
| bankruptcy | 缺口、主因（维护/伤亡/枯竭） |
| fort_breach | 用时、弱点是否先破 |

**成功指标**（好玩的可操作定义）：
- 人类首局完成率 ≥ 70%；重开率（结算后 60s 内再开）≥ 40%
- Agnes 基准：标准图 AI 胜率落在 30-60% 区间（<30% 太难，>60% 太浅）
- 中位局时 15-30 分钟，越界即调节点数/维护费

## 商业化
Premium 买断（对标 Slipways ¥57 / Thronefall ¥52），无内购、无广告。
强度类内容永不售卖；创意工坊/自定义指挥官为远期。

## 无障碍
色盲模式（形状双编码已内建）；全局速度调节 ×0.75-×1.5；RTP 暂停即核心无障碍。

## 本地化
中文优先；字符串表外置 JSON（**STG 教训：UI 文案硬编码进代码难以抽取**）。
