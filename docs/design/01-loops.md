# 01 三层循环与情绪曲线

## 瞬时循环（秒级，战术层）
走位躲弹 → 擦弹积张力 → 张力满释放潮涌 → 技能时机（护盾/集火/佯攻）
**验收：每 30 秒游戏必须给玩家至少一个主动决策点**（STG 的教训：全自动=无聊根源）

## 局内循环（分钟级，战略层⇄战术层）
占节点 → 连供应链 → 造舰/换编成 → 画路线派舰队 → 战术遭遇（弹幕） →
破节点/守军反扑 → 波末结算（维护费 vs 收入） → 循环至要塞

## 局外循环（天级）
见 `05-meta.md`：指挥官图鉴（知识积累即成长）、天赋解锁、每日种子挑战。

## 情绪曲线（一局的标准弧线）
开局布阵（期待）→ 首战告捷（掌握感）→ 多路取舍（紧张）→ 收支危机（压力峰值）
→ 要塞战（释放）→ 归因结算（学习+立即重开）
**设计约束：压力峰值只允许出现一次/局**——多路倒计时的到期波必须错峰。
