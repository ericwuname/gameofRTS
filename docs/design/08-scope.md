# 08 MVP 砍单清单 / 里程碑 / 风险 / 决策日志

## 砍单清单（Cut List）——预算固定的前提下最先砍谁
| 级别 | 内容 |
|---|---|
| MUST | 单路+多路海图、单级供应链、3 兵种、3 守军塔、2 条指挥官规则（增援/伏击）、归因结算 |
| SHOULD | 精炼级链、5 条指挥官规则、侦察迷雾、指挥官图鉴 |
| LATER | 每日种子挑战、天赋全池、弱点机制扩展、工坊/自定义指挥官、多平台 |

## 里程碑（M1-M4，约 7 天）+ 验收标准
| 里程碑 | 内容 | 验收 |
|---|---|---|
| M1（2天） | 海图节点+舰队路线+3 守军+旗舰走位 | 人类可打穿一条防线且重开率>0 |
| M2（2天） | 供应链+造舰+维护费破产 | 破产可发生且归因正确 |
| M3（1.5天） | 随机生成管线+2 条指挥官规则 | 同 seed 复现同图；校验拦截不可玩图 |
| M4（1.5天） | 图鉴+剩余规则+Agnes 验证门 | Agnes 胜率落 30-60%；指标全绿 |
