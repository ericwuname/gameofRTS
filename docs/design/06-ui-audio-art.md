# 06 UI / 音频 / 视觉（缺口补全）

## 屏幕流
主菜单 →（机体+天赋池预览）→ 海图（战略层）⇄ 战术遭遇 → 波末结算 →（循环）→
归因结算 → 图鉴/重开
**STG 三教训固化成 UI 三原则**：
1. **进度永不隐藏**——所有攒积类资源（潮力/张力/建造进度）常驻可见，压暗而非隐藏
2. **状态永远可读**——收支表常驻；指挥官规则开局公示一半
3. **每个系统开花必有视觉反馈**——新机制上线必带专属特效，否则玩家以为没生效

## 音频（复用程序化 Sfx，零音频资产）
- 战略层：环境潮声底噪 + 占领/连线确认音
- 战术层：警报/弹幕/爆炸（TideShot 现成）
- **指挥官人格给音乐动机**：伏击=低频震音、增援=行进鼓点、焦土=风啸——
  用听觉预告敌方行为，比 UI 提示更高级

## 视觉（程序化几何风格，零美术资产是差异化优势）
- 色彩语义继承 TideShot：**暖色=威胁，青色=我方**，金色=资源
- 海图：深蓝底 + 节点几何形状区分类型（矿=菱形、厂=方形、要塞=六边形）
- 形状双编码天然服务色盲模式（见 07）
