# 00 愿景与定位（事实源）

> 模块化设计文档入口。v2-v4 调研全文见 `DESIGN-TideBreaker.md`（历史档案）。
> 变更规则：改设计先改这里或对应模块，再动代码；每次转向记入 `08-scope.md` 决策日志。

## 一句话 Pitch
**15-30 分钟一局的攻方海战棋：你调度舰队、经营供应链、亲自驾旗舰躲弹，
攻破每局随机生成、各有"人格"的汐庭防线。**

## 三大设计支柱（一切争议以此裁决）
1. **调度 > 微操**：画路线 + 时机决策，永远不做框选微操
2. **布局即博弈**：围棋式节点占领 + 连线不交叉的平面约束
3. **输得明白**：失败归因结算 + 敌方规则公示，随机重但不糊涂

## 目标玩家
- 主：碎片时间策略玩家（Slipways / Thronefall 受众），一局一顿饭
- 辅：有 STG 手感的玩家（旗舰走位层承接 TideShot 老玩家）

## 竞品与差异
| 竞品 | 它有 | 它没有（=我们的位置） |
|---|---|---|
| Slipways | 布局经济 | 战斗与敌方 AI |
| Anomaly | 攻方调度 | 经济布局与 Build |
| Mindustry | 供应链 | 攻方视角、轻量化（无传送带模拟） |
| FTL | 稀缺压力 | 布局层与实时弹幕 |

## 这个游戏"不是什么"（防范围蔓延）
- 不是框选 RTS（无多选、无 APM 要求）
- 不是塔防（你是攻方）
- 不是 4X（无探索大地图、无外交）
- MVP 不做多人、不做 PVP

## 平台与形态
PC（Steam）优先；输入方案天然兼容触屏（画线+点选）。
